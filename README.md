# Maclawrence / Maciboi — GitHub-ready portfolio

## Files
- index.html
- style.css
- script.js
- assets/

## Upload to GitHub
Upload these files DIRECTLY into the ROOT of your repository:
`index.html`, `style.css`, `script.js`, and the `assets` folder.

Do not create a nested `Maclawrence-GitHub-Ready` folder inside the repository.

No Node.js, npm, React, Vite or build step is required.

## Photos
The website includes Add Photo buttons for:
- Profile
- Southgold / school
- Favourite food
- Football

The selected images are saved in the browser using IndexedDB, so they can remain after a refresh on the same device/browser. They are not uploaded to GitHub or to a server.

For a permanent photo that everyone visiting the GitHub Pages site can see, add the actual image to `assets/` and change the relevant image element in `index.html`.

## Contact form
The form is currently a practice/demo form. It does not send email until you connect an email service.
